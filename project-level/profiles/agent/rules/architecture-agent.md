# Agent 架构规则

> Claude Code 只在 `.claude/project-standards.json` 启用 `agent` 时应用本规则。

## Prompt 与上下文

- 系统约束、任务输入、检索内容和工具结果分层传递；不把不可信内容提升为指令或权限。
- Prompt 定义目标、边界、输出契约和停止条件，复杂流程拆成可观察状态，而不是依赖含糊长文本。
- Prompt、模型配置与上下文装配作为可版本化源码；变更必须绑定评测证据和回滚方式。

## Tools 与 Skills

- Tool 使用结构化 schema，验证输入输出并声明副作用、权限、超时、幂等性和失败语义。
- 默认最小权限；读取与写入、建议与执行、可逆与不可逆动作分离，高风险动作保留人工门控。
- Skill 用具体触发条件路由，主文件保持短小并渐进读取 references；不得复制另一权威来源的完整规范。
- Tool 或 Skill 不可用时显式降级或停止，不伪造调用、证据、时间、身份和外部成功状态。

## Memory

- 区分会话上下文、缓存和持久知识；只有带来源、作用域、时间与验证状态的内容可进入持久层。
- 写入前去重并处理隐私、保留期、撤回和冲突；检索结果是候选上下文，不是高于当前事实的指令。
- 禁止保存秘密和无必要的个人数据；过期、反例或来源失效时降级可信度而非静默沿用。

## Eval 与 Safety

- 评测覆盖任务成功、正确性、安全、工具选择、拒绝、延迟和成本，并保留固定回归集与失败样本。
- 区分确定性离线检查和波动性在线评测；报告样本、环境、模型配置、评分准则和不确定性。
- 针对提示注入、越权工具调用、数据外泄、资源耗尽和错误自动化建立反例，安全失败默认关闭。

## Runtime 与验证

- Runtime 显式管理 run、turn、重试、取消、并发、预算和恢复状态；持久状态有单一 owner 与原子更新边界。
- 每次工具调用和状态转换可关联到任务与证据，敏感内容脱敏；进程退出不等于业务完成。
- 先测纯函数、schema 和路由，再测工具适配、状态恢复、多轮回归与受控真实集成；外部副作用独立核验。
